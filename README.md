# ESP32 IP Intercom System

## 📌 Description
This project implements an IP-based intercom system using an ESP32 microcontroller and an Asterisk SIP server.

A visitor can press a push button to trigger a call to remote users via VoIP. The users receive the call on their smartphones and can communicate with the visitor.

## ⚙️ Features
- Push button triggers call to users (2001 & 2002)
- Communication via VoIP (Zoiper)
- LED control using keypad (DTMF)
- Buzzer notification when button is pressed

## 🧰 Hardware
- ESP32-S3 CAM
- Push button
- LED
- Buzzer

## 💻 Technologies
- Asterisk (SIP server)
- Arduino IDE (C++)
- Python (DTMF detection via AMI)
- SIP / VoIP protocol
